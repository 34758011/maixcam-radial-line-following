# 设计与参数

## 与原始扫描逻辑的关系

保留固定圆心、前半圆、半径递增扫描，未改成行扫描、骨架算法或神经网络。圆心在ROI底部中间；图像坐标x向右、y向下，因此270°表示正前方。

弧段用 `(x, y, angle_start, angle_end)` 表示。预测点不作为实测弧心加入路径。连接拐点是经过当前图像道路验证的显示连接点，不作为扫描观测或跨帧历史。

## 关联与路口

普通关联依次检查预测距离、极角变化、行进方向，再验证连接中的道路覆盖率和连续白色采样长度。每个候选只有一个前驱，同一前驱可以分叉。

弧长相对近期基准明显增宽时启用疑似路口门限。合并宽弧的中点漂移不更新可靠入路方向；窄分支出现后再用实测方向延伸。十字路口可包含直行、左、右多个出口。

在分叉处，通常要求后续至少两层证据；接近ROI侧边且道路证据很强的出口允许更短。主路线比较分支后面数层相对入路方向的转角。`TURN_MODE`决定分叉时的偏好；只有一个可达方向时沿该方向继续，包括正常的左右弯道。

## 参数

| 参数 | 默认 | 作用 |
|---|---:|---|
| `THRESHOLD` | 70 | 原图黑色灰度阈值 |
| `ROAD_PIXEL` | 255 | 反向二值化后的道路值 |
| `RADIUS_STEP` | 10 | 扫描半径间隔，像素 |
| `ANGLE_STEP` | 1.0 | 圆周角步长，度 |
| `MAX_EMPTY_LAYERS` | 1 | 每支最多跨一层，跨缺口显示虚线 |
| `MIN_PATH_POINTS` | 3 | 输出路线最少实测点数 |
| `MIN_BRANCH_POINTS` | 2 | 分叉后需要的持续证据 |
| `MAX_ARCS_PER_LAYER` / `MAX_NODES` | 12 / 256 | 计算量约束 |
| `MIN_LINE_SUPPORT` | 0.72 | 普通连接最低道路覆盖率 |
| `MAX_WHITE_RUN` | 3 | 普通连接最多连续白色采样数 |
| `JUNCTION_WIDTH_RATIO` / `JUNCTION_WIDTH_MARGIN` | 1.6 / 4 | 疑似路口弧长增宽门限 |
| `JUNCTION_HOLD_LAYERS` | 4 | 路口转向门限保留层数 |
| `HISTORY_WEIGHT` | 0.20 | 上一可靠路线的弱评分影响 |
| `HISTORY_RESET_FRAMES` | 3 | 连续丢失后清除历史 |
| `FLOOD_RATIO` | 0.80 | 大面积黑色异常门限 |

步长、距离和角度门限需为正，允许缺失层数需为非负整数。改变扫描参数后重启脚本。先调二值识别，再调关联门限，不建议把全部门限同时放宽。

## 输出

`analyze(roi, scanner, history)` 返回 `path`、`links`、`main_links`、`status`、`branches`、`confidence` 和 `error`。

- `path`：按半径排序的实测主路线。
- `links` / `main_links`：全部可达连接与主线连接，包含是否跨缺口的标志。
- `status`：`tracking`、`branch`、`lost`、`insufficient`或`mask_flood`。
- `branches`：保留树的叶端数量，不等于严格校准过的道路拓扑数量。
- `confidence`：证据量与覆盖率的启发式分数，不是概率。
- `error`：近中场归一化横向偏差，负数在左，正数在右；丢失时None。不是转向执行命令。

## 上板检查

依次测试直线、偏侧窄线、缓弯、左右直角、T/Y/十字、断线、噪声及不同光照。分别记录预处理、关联、整帧延迟及最坏路口耗时；不要用桌面合成测试耗时声称硬件实时性。实际执行转弯还需要与电机接口、速度和闭环控制共同验证。
